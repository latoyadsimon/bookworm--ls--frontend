3. Browse by Genre Page Route: /genre/:genre

User Story

As a visitor, I want to browse books by genre, so that I can find books that match what I'm in the mood to read.

Key Elements

  • Navigation bar (Genres ▾ menu)
  • Genre chips: Adventure, Technology, Horror, Sci-Fi, Fiction, Non-Fiction
  • Selected genre highlighted
  • Genre heading
  • Book grid (cover, title, author)
  • Load More button
