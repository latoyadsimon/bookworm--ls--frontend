2. Search Results Page Route: /search?q=:query&type=:type

User Story

As a visitor, I want to search for books by title, author, ISBN, or keyword, so that I can quickly find a specific book or books like it.

Key Elements

  • Navigation bar
  • Search box (pre-filled from URL)
  • Type dropdown: All / Title / Author / ISBN
  • Results heading with query
  • Results grid (cover, title, author)
  • Load More button
  • No-results + validation messages
